# Slosh

A liquid you can tilt, shake and stir. Open `index.html` over **https** on a phone or tablet to use the gyro.

## Put it online (GitHub Pages)
1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**, pick this branch and `/ (root)`, then Save
3. After about a minute, open `https://<your-username>.github.io/<repo-name>/` in Safari or Chrome and tap **Start**, then **Allow**
